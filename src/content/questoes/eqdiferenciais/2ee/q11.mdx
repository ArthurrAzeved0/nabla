Usando séries de potências em torno de $x_0 = 0$, resolva o problema de valor inicial:

$$
y' + xy = \alpha + \beta x, \qquad y(0) = \beta
$$

onde $\alpha$ e $\beta$ são constantes. Escreva os primeiros termos da solução.

<Gabarito>
$y(x) = \beta + \alpha\left(x - \dfrac{x^3}{3} + \dfrac{x^5}{15} - \dfrac{x^7}{105} + \cdots\right)$, com recorrência $a_{m+1} = -\dfrac{a_{m-1}}{m+1}$ para $m \ge 2$.
</Gabarito>

<Passos>
**Passo 1 —** Propomos $y = \displaystyle\sum_{n=0}^{\infty} a_nx^n$, logo $y' = \displaystyle\sum_{n=1}^{\infty} na_nx^{n-1}$ e $xy = \displaystyle\sum_{n=0}^{\infty} a_nx^{n+1}$.

**Passo 2 —** Reindexando tudo em potências $x^m$:

$$
y' + xy = a_1 + \sum_{m=1}^{\infty}\big[(m+1)a_{m+1} + a_{m-1}\big]x^m = \alpha + \beta x
$$

**Passo 3 —** Igualando os coeficientes:

• $x^0$: $a_1 = \alpha$;<br />
         • $x^1$: $2a_2 + a_0 = \beta$. Como $y(0) = a_0 = \beta$, vem $a_2 = 0$;<br />
         • $x^m$ ($m \ge 2$): $(m+1)a_{m+1} + a_{m-1} = 0 \Rightarrow a_{m+1} = -\dfrac{a_{m-1}}{m+1}$.

**Passo 4 —** A recorrência salta de 2 em 2. Ramo par (a partir de $a_2 = 0$): todos nulos. Ramo ímpar (a partir de $a_1 = \alpha$):

$$
a_3 = -\frac{a_1}{3} = -\frac{\alpha}{3}, \quad a_5 = -\frac{a_3}{5} = \frac{\alpha}{15}, \quad a_7 = -\frac{a_5}{7} = -\frac{\alpha}{105}
$$

**Passo 5 —** Solução:

$$
\boxed{y(x) = \beta + \alpha\left(x - \frac{x^3}{3} + \frac{x^5}{15} - \frac{x^7}{105} + \cdots\right)}
$$

Padrão dos denominadores: $1,\ 1\cdot3,\ 1\cdot3\cdot5,\ 1\cdot3\cdot5\cdot7,\ \dots$ (produto dos ímpares).
</Passos>
