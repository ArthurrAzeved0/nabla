Considere a EDO $y''' - 3y'' + 2y' = r(x)$.

a) Encontre a solução para $r(x) = 0$ (1,0 pt);<br />
       b) Encontre a solução geral para $r(x) = e^{3x} - \cos x$ (1,5 pts).

<Gabarito>
$y = C_1 + C_2e^{x} + C_3e^{2x} + \dfrac{e^{3x}}{6} - \dfrac{1}{10}(\operatorname{sen} x + 3\cos x)$.
</Gabarito>

<Passos>
**Passo 1 (a) —** Equação característica:

$$
m^3 - 3m^2 + 2m = m(m^2 - 3m + 2) = m(m-1)(m-2) = 0 \;\Rightarrow\; m = 0,\ 1,\ 2
$$

$$
y_h = C_1 + C_2e^{x} + C_3e^{2x}
$$

**Passo 2 (b) —** Como $3$, $\pm i$ não são raízes, tentamos:

$$
y_p = Ae^{3x} + B\operatorname{sen} x + C\cos x
$$

**Passo 3 —** Derivadas: $y_p' = 3Ae^{3x} + B\cos x - C\operatorname{sen} x$, $y_p'' = 9Ae^{3x} - B\operatorname{sen} x - C\cos x$, $y_p''' = 27Ae^{3x} - B\cos x + C\operatorname{sen} x$. Substituindo:

$$
6Ae^{3x} + (C + 3B - 2C)\operatorname{sen} x + (-B + 3C + 2B)\cos x = e^{3x} - \cos x
$$

**Passo 4 —** Igualando os coeficientes:

• $e^{3x}$: $6A = 1 \Rightarrow A = \dfrac16$;<br />
         • $\operatorname{sen} x$: $3B - C = 0$;<br />
         • $\cos x$: $B + 3C = -1$.

De $C = 3B$: $B + 9B = -1 \Rightarrow B = -\dfrac{1}{10}$, $C = -\dfrac{3}{10}$.

**Passo 5 —** Solução geral:

$$
\boxed{y = C_1 + C_2e^{x} + C_3e^{2x} + \frac{e^{3x}}{6} - \frac{1}{10}\big(\operatorname{sen} x + 3\cos x\big)}
$$
</Passos>
