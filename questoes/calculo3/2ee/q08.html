Questão 08 2º EE · 2025.1 Trabalho · campo conservativo 2,0 pts

Utilizando o conceito de integral de linha de campo vetorial, determine o trabalho realizado pelo campo de força

$$\vec F(x,y,z) = (y+z,\; x+z,\; x+y)$$

sobre uma partícula que se move ao longo do segmento de reta de \((1,0,0)\) a \((3,4,2)\).

Gabarito

\(W = 26\) (o campo é conservativo, com potencial \(f = xy + yz + xz\)).

Passo a passo

Passo 1 — Antes de parametrizar, teste se \(\vec F\) é conservativo. Com \(P = y+z\), \(Q = x+z\), \(R = x+y\), o rotacional é nulo:

$$P_y = 1 = Q_x,\qquad P_z = 1 = R_x,\qquad Q_z = 1 = R_y$$

Como \(\vec F\) está definido em todo o \(\mathbb R^3\) (simplesmente conexo) e \(\nabla\times\vec F = \vec 0\), o campo é conservativo.

Passo 2 — Ache a função potencial \(f\) com \(\nabla f = \vec F\). De \(f_x = y+z\):

$$f = xy + xz + g(y,z)$$

Derive em \(y\): \(f_y = x + g_y = x + z \Rightarrow g_y = z \Rightarrow g = yz + h(z)\). Derive em \(z\): \(f_z = x + y + h'(z) = x + y \Rightarrow h'(z) = 0\). Logo

$$f(x,y,z) = xy + yz + xz$$

Passo 3 — Pelo Teorema Fundamental das integrais de linha, o trabalho só depende dos extremos (o segmento em si é irrelevante):

$$W = \int_C \vec F\cdot d\vec r = f(3,4,2) - f(1,0,0)$$

Passo 4 — Avalie:

$$f(3,4,2) = 3\cdot4 + 4\cdot2 + 3\cdot2 = 12 + 8 + 6 = 26,\qquad f(1,0,0) = 0$$ $$W = 26 - 0 = 26$$
