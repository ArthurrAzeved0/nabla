Questão 12 2º EE · 2025.1 Integral de superfície · cone 2,0 pts

Calcule a integral de superfície

$$\iint_S x^2 z^2\,dS$$

onde \(S\) é a parte do cone \(z^2 = x^2 + y^2\) que está entre os planos \(z=1\) e \(z=3\).

Gabarito

\(\displaystyle\iint_S x^2 z^2\,dS = \frac{364\sqrt{2}\,\pi}{3}\)

Passo a passo

Passo 1 — Escreva o cone como gráfico \(z = f(x,y) = \sqrt{x^2+y^2}\). O elemento de área é

$$dS = \sqrt{1 + z_x^2 + z_y^2}\,dA,\qquad z_x = \frac{x}{\sqrt{x^2+y^2}},\; z_y = \frac{y}{\sqrt{x^2+y^2}}$$ $$z_x^2 + z_y^2 = \frac{x^2+y^2}{x^2+y^2} = 1 \quad\Rightarrow\quad dS = \sqrt{2}\,dA$$

Passo 2 — No cone, \(z^2 = x^2+y^2\), então o integrando fica

$$x^2 z^2 = x^2(x^2+y^2)$$

Passo 3 — Passe para polares: \(x = r\cos\theta\), \(x^2+y^2 = r^2\). Como \(z = r\), a faixa \(1\le z\le 3\) vira \(1\le r\le 3\), com \(0\le\theta\le 2\pi\). O integrando:

$$x^2(x^2+y^2) = (r^2\cos^2\theta)(r^2) = r^4\cos^2\theta$$

Passo 4 — Monte a integral (lembrando \(dA = r\,dr\,d\theta\) e o fator \(\sqrt{2}\)):

$$\iint_S x^2 z^2\,dS = \sqrt{2}\int_0^{2\pi}\!\!\int_1^3 r^4\cos^2\theta\cdot r\,dr\,d\theta = \sqrt{2}\int_0^{2\pi}\cos^2\theta\,d\theta\int_1^3 r^5\,dr$$

Passo 5 — As duas integrais:

$$\int_0^{2\pi}\cos^2\theta\,d\theta = \pi,\qquad \int_1^3 r^5\,dr = \left[\frac{r^6}{6}\right]_1^3 = \frac{729-1}{6} = \frac{364}{3}$$ $$\iint_S x^2 z^2\,dS = \sqrt{2}\cdot\pi\cdot\frac{364}{3} = \frac{364\sqrt{2}\,\pi}{3}$$
