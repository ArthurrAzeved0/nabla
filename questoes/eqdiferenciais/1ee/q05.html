Questão 05 1º EE · 2025.1 PVI · fator integrante 2,5 pts

Resolva o problema de valor inicial

$$\frac{1}{x}\,\frac{dy}{dx} - \frac{2y}{x^2} = x\cos x, \qquad y(\pi) = \pi^3$$
Gabarito

\(y(x) = x^2\operatorname{sen} x + \pi x^2\).

Passo a passo

Passo 1 — Multiplique tudo por \(x\) para chegar à forma padrão:

$$\frac{dy}{dx} - \frac{2}{x}\,y = x^2\cos x \qquad\Rightarrow\qquad P(x) = -\frac{2}{x}$$

Passo 2 — Fator integrante:

$$\mu(x) = e^{\int -\frac{2}{x}dx} = e^{-2\ln x} = \frac{1}{x^2}$$

Passo 3 — Multiplicando por \(\mu\):

$$\frac{d}{dx}\left(\frac{y}{x^2}\right) = \frac{1}{x^2}\cdot x^2\cos x = \cos x$$

Passo 4 — Integrando em relação a \(x\):

$$\frac{y}{x^2} = \operatorname{sen} x + C \;\Rightarrow\; y = x^2\operatorname{sen} x + Cx^2$$

Passo 5 — Condição inicial \(y(\pi) = \pi^3\): como \(\operatorname{sen}\pi = 0\),

$$C\pi^2 = \pi^3 \;\Rightarrow\; C = \pi \qquad\Rightarrow\qquad \boxed{y = x^2\operatorname{sen} x + \pi x^2}$$
