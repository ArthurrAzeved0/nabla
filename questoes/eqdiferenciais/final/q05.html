Questão 05 Final · 2023.2 Série de potências · coeficiente variável 2,5 pts

Encontre uma solução geral para

$$y'' + (\cos x)\,y = 0$$

na forma de série de potências em \(x\), escrevendo os primeiros termos de cada solução.

Gabarito

\(y = c_0\left[1 - \dfrac{x^2}{2} + \dfrac{x^4}{12} - \cdots\right] + c_1\left[x - \dfrac{x^3}{6} + \dfrac{x^5}{30} - \cdots\right]\)

Passo a passo

Passo 1 — O truque desta questão: expandir também o \(\cos x\) em série!

$$\cos x = 1 - \frac{x^2}{2!} + \frac{x^4}{4!} - \cdots$$

Passo 2 — Com \(y = \sum c_nx^n\), substituímos e multiplicamos as séries:

$$y'' + (\cos x)y = \sum_{n=2}^{\infty} n(n-1)c_nx^{n-2} + \left(1 - \frac{x^2}{2} + \cdots\right)\sum_{n=0}^{\infty} c_nx^n = 0$$

Passo 3 — Agrupando por potências de \(x\):

$$\big(2c_2 + c_0\big) + \big(6c_3 + c_1\big)x + \left(12c_4 + c_2 - \frac{c_0}{2}\right)x^2 + \cdots = 0$$

Passo 4 — Anulando cada coeficiente:

• \(c_2 = -\dfrac{c_0}{2}\);
• \(c_3 = -\dfrac{c_1}{6}\);
• \(12c_4 = \dfrac{c_0}{2} - c_2 = \dfrac{c_0}{2} + \dfrac{c_0}{2} = c_0 \Rightarrow c_4 = \dfrac{c_0}{12}\);
• analogamente \(c_5 = \dfrac{c_1}{30}\).

Passo 5 — Separando em duas soluções LI (uma multiplicando \(c_0\), outra \(c_1\)):

$$\boxed{y = c_0\left[1 - \frac{x^2}{2} + \frac{x^4}{12} - \cdots\right] + c_1\left[x - \frac{x^3}{6} + \frac{x^5}{30} - \cdots\right]}$$
