Questão 07 Final · 2023.2 Sistema 3×3 · autovalor repetido 2,5 pts

Encontre a solução para \(x_1(t)\), \(x_2(t)\) e \(x_3(t)\) do sistema de EDOs. Um dos autovalores é \(\lambda = -1\).

$$\begin{cases} x_1' = 2x_1 + x_3 \\ x_2' = -2x_2 + x_3 \\ x_3' = -x_2 \end{cases}$$
Gabarito

\(\lambda = -1\) (duplo) e \(\lambda = 2\); \(V_1 = \begin{pmatrix}1\\-3\\-3\end{pmatrix}\), \(W = \begin{pmatrix}0\\4\\1\end{pmatrix}\), \(V_3 = \begin{pmatrix}1\\0\\0\end{pmatrix}\);   \(X = c_1e^{-t}V_1 + c_2\big(tV_1 + W\big)e^{-t} + c_3e^{2t}V_3\).

Passo a passo

Passo 1 — \(A = \begin{pmatrix} 2 & 0 & 1 \\ 0 & -2 & 1 \\ 0 & -1 & 0 \end{pmatrix}\). Polinômio característico:

$$\det(A - \lambda I) = (2-\lambda)(-2-\lambda)(-\lambda) + (2-\lambda) = 0 \;\Longleftrightarrow\; \lambda^3 - 3\lambda - 2 = 0$$

Passo 2 — Usando Briot-Ruffini com a raiz dada \(\lambda = -1\):

$$\frac{\lambda^3 - 3\lambda - 2}{\lambda + 1} = \lambda^2 - \lambda - 2 = (\lambda+1)(\lambda-2) \;\Rightarrow\; \lambda_{1,2} = -1 \text{ (duplo)},\ \lambda_3 = 2$$

Passo 3 — Autovetor para \(\lambda = -1\): \((A+I)V = 0\) dá \(3v_1 + v_3 = 0\) e \(v_2 = v_3\). Com \(v_1 = 1\):

$$V_1 = \begin{pmatrix}1\\-3\\-3\end{pmatrix}$$

Só há um autovetor independente para \(\lambda = -1\) — precisamos do autovetor generalizado.

Passo 4 — Generalizado: \((A+I)W = V_1\), ou seja \(3w_1 + w_3 = 1\) e \(-w_2 + w_3 = -3\). Com \(w_1 = 0\): \(w_3 = 1\), \(w_2 = 4\):

$$W = \begin{pmatrix}0\\4\\1\end{pmatrix}$$

Passo 5 — Autovetor para \(\lambda_3 = 2\): \((A-2I)V = 0\) dá \(v_3 = 0\), \(v_2 = 0\), \(v_1\) livre:

$$V_3 = \begin{pmatrix}1\\0\\0\end{pmatrix}$$

Passo 6 — Solução geral \(X = c_1V_1e^{-t} + c_2(tV_1 + W)e^{-t} + c_3V_3e^{2t}\), componente a componente:

$$\boxed{\begin{aligned} x_1 &= c_1e^{-t} + c_2\,te^{-t} + c_3e^{2t} \\ x_2 &= -3c_1e^{-t} + c_2(-3te^{-t} + 4e^{-t}) \\ x_3 &= -3c_1e^{-t} + c_2(-3te^{-t} + e^{-t}) \end{aligned}}$$
