Questão 13 2º EE · 2025.2 Série de potências · PVI 2,5 pts

Considere a equação diferencial:

$$(x^2 - 4)y'' + 3xy' + y = 0$$

a) Verifique que \(x_0 = 0\) é ponto ordinário e encontre a relação de recorrência da solução em série;
b) Resolva o problema de valor inicial com \(y(0) = 4\) e \(y'(0) = 1\), escrevendo os primeiros termos.

Gabarito

\(c_{n+2} = \dfrac{(n+1)c_n}{4(n+2)}\);   \(y(x) = 4 + x + \dfrac{x^2}{2} + \dfrac{x^3}{6} + \dfrac{3x^4}{32} + \dfrac{x^5}{30} + \cdots\)

Passo a passo

Passo 1 (a) — Os pontos singulares vêm de \(x^2 - 4 = 0\), ou seja \(x = \pm 2\). Como \(x_0 = 0\) não anula o coeficiente líder, é ponto ordinário (raio de convergência mínimo: distância até a singularidade mais próxima, \(R \ge 2\)).

Passo 2 — Com \(y = \sum c_nx^n\), substituímos e separamos \((x^2-4)y'' = x^2y'' - 4y''\):

$$\sum_{n=0}^{\infty}\Big[n(n-1)c_n - 4(n+2)(n+1)c_{n+2} + 3nc_n + c_n\Big]x^n = 0$$

Passo 3 — Como \(n(n-1) + 3n + 1 = n^2 + 2n + 1 = (n+1)^2\):

$$(n+1)^2c_n = 4(n+2)(n+1)c_{n+2} \;\Rightarrow\; \boxed{c_{n+2} = \frac{(n+1)\,c_n}{4(n+2)}}$$

Passo 4 (b) — Condições iniciais: \(c_0 = 4\), \(c_1 = 1\). Aplicando a recorrência:

• \(n=0\): \(c_2 = \dfrac{1\cdot 4}{4\cdot 2} = \dfrac12\);
• \(n=1\): \(c_3 = \dfrac{2\cdot 1}{4\cdot 3} = \dfrac16\);
• \(n=2\): \(c_4 = \dfrac{3\cdot(1/2)}{4\cdot 4} = \dfrac{3}{32}\);
• \(n=3\): \(c_5 = \dfrac{4\cdot(1/6)}{4\cdot 5} = \dfrac{1}{30}\).

Passo 5 — Solução do PVI:

$$\boxed{y(x) = 4 + x + \frac{x^2}{2} + \frac{x^3}{6} + \frac{3x^4}{32} + \frac{x^5}{30} + \cdots}$$
