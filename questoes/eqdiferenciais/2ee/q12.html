Questão 12 Revisão 2º EE · Prof. César Série de potências · \(x_0 = 1\) 1,0 pt

Resolva por séries de potências, em torno de \(x_0 = 1\), o problema de valor inicial:

$$xy'' + y' + 2y = 0, \qquad y(1) = 0, \quad y'(1) = 4$$

Escreva os primeiros termos da solução.

Gabarito

\(y(x) = 4(x-1) - 2(x-1)^2 + \dfrac{1}{3}(x-1)^4 - \dfrac{4}{15}(x-1)^5 + \cdots\)

Passo a passo

Passo 1 — Mudança de variável \(t = x - 1\) (assim \(x = t + 1\) e as derivadas não mudam):

$$(t+1)y'' + y' + 2y = 0, \qquad y(0) = 0, \quad y'(0) = 4$$

Passo 2 — Com \(y = \sum a_nt^n\), separando \((t+1)y'' = ty'' + y''\):

$$\sum_{m=1}^{\infty} (m+1)m\,a_{m+1}t^m + \sum_{m=0}^{\infty} (m+2)(m+1)a_{m+2}t^m + \sum_{m=0}^{\infty}(m+1)a_{m+1}t^m + \sum_{m=0}^{\infty} 2a_mt^m = 0$$

Passo 3 — Coeficiente de \(t^m\):

$$(m+2)(m+1)a_{m+2} + (m+1)^2a_{m+1} + 2a_m = 0 \;\Rightarrow\; a_{m+2} = \frac{-(m+1)^2a_{m+1} - 2a_m}{(m+2)(m+1)}$$

Passo 4 — Condições iniciais: \(a_0 = 0\), \(a_1 = 4\). Aplicando a recorrência:

• \(m=0\): \(a_2 = \dfrac{-a_1 - 2a_0}{2} = -2\);
• \(m=1\): \(a_3 = \dfrac{-4a_2 - 2a_1}{6} = \dfrac{8 - 8}{6} = 0\);
• \(m=2\): \(a_4 = \dfrac{-9a_3 - 2a_2}{12} = \dfrac{4}{12} = \dfrac13\);
• \(m=3\): \(a_5 = \dfrac{-16a_4 - 2a_3}{20} = \dfrac{-16/3}{20} = -\dfrac{4}{15}\).

Passo 5 — Voltando a \(x\) (com \(t = x-1\)):

$$\boxed{y(x) = 4(x-1) - 2(x-1)^2 + \frac{1}{3}(x-1)^4 - \frac{4}{15}(x-1)^5 + \cdots}$$
