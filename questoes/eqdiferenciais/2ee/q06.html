Questão 06 Revisão 2º EE · Prof. César Sistema não homogêneo · coef. indeterminados 1,0 pt

Encontre a solução geral do sistema não homogêneo:

$$X' = \begin{pmatrix} 4 & 3 \\ -1 & 0 \end{pmatrix}X + \begin{pmatrix} t \\ 0 \end{pmatrix}$$
Gabarito

\(X(t) = c_1\begin{pmatrix}1\\-1\end{pmatrix}e^{t} + c_2\begin{pmatrix}3\\-1\end{pmatrix}e^{3t} + \begin{pmatrix}0\\-1/3\end{pmatrix}t + \begin{pmatrix}1/3\\-4/9\end{pmatrix}\).

Passo a passo

Passo 1 — Parte homogênea. Autovalores:

$$\det(A-\lambda I) = \lambda^2 - 4\lambda + 3 = 0 \;\Rightarrow\; \lambda_1 = 1,\ \lambda_2 = 3$$

Passo 2 — Autovetores. Para \(\lambda_1 = 1\): \(\begin{pmatrix}3&3\\-1&-1\end{pmatrix}K=0 \Rightarrow K_1 = \begin{pmatrix}1\\-1\end{pmatrix}\). Para \(\lambda_2 = 3\): \(\begin{pmatrix}1&3\\-1&-3\end{pmatrix}K=0 \Rightarrow K_2 = \begin{pmatrix}3\\-1\end{pmatrix}\).

$$X_h = c_1\begin{pmatrix}1\\-1\end{pmatrix}e^{t} + c_2\begin{pmatrix}3\\-1\end{pmatrix}e^{3t}$$

Passo 3 — Como \(F(t) = \begin{pmatrix}t\\0\end{pmatrix}\) é polinomial de grau 1, tentamos \(X_p = \mathbf{a}t + \mathbf{b}\). Substituindo \(X_p' = \mathbf{a}\):

$$\mathbf{a} = A(\mathbf{a}t + \mathbf{b}) + \begin{pmatrix}1\\0\end{pmatrix}t$$

Igualando os coeficientes de \(t\): \(A\mathbf{a} + \begin{pmatrix}1\\0\end{pmatrix} = 0\). Igualando os termos constantes: \(A\mathbf{b} = \mathbf{a}\).

Passo 4 — De \(A\mathbf{a} = \begin{pmatrix}-1\\0\end{pmatrix}\): \(4a_1 + 3a_2 = -1\) e \(-a_1 = 0\), logo \(a_1 = 0\), \(a_2 = -\tfrac13\), ou seja \(\mathbf{a} = \begin{pmatrix}0\\-1/3\end{pmatrix}\).

Passo 5 — De \(A\mathbf{b} = \mathbf{a}\): \(4b_1 + 3b_2 = 0\) e \(-b_1 = -\tfrac13\), logo \(b_1 = \tfrac13\), \(b_2 = -\tfrac49\), ou seja \(\mathbf{b} = \begin{pmatrix}1/3\\-4/9\end{pmatrix}\).

Passo 6 — Solução geral:

$$\boxed{X(t) = c_1\begin{pmatrix}1\\-1\end{pmatrix}e^{t} + c_2\begin{pmatrix}3\\-1\end{pmatrix}e^{3t} + \begin{pmatrix}0\\-1/3\end{pmatrix}t + \begin{pmatrix}1/3\\-4/9\end{pmatrix}}$$
